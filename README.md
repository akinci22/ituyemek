# İTÜ Yemek & Kalori

İТÜ yemekhane menüsünü gösterip yediğin **kalori, makro (protein/karbonhidrat/yağ), su ve
adım** takibini yapan ücretsiz araç. Hesap yok, reklam yok, veriler cihazda kalır.

**🌐 Web sürümü:** https://akinci22.github.io/ituyemek/
**🔒 Gizlilik:** https://akinci22.github.io/ituyemek/privacy.html

> Bu uygulama İstanbul Teknik Üniversitesi'nin **resmi uygulaması değildir**; öğrenciler için
> yapılmış bağımsız bir yardımcı araçtır.

## Özellikler
- Günün öğle/akşam menüsü, gerçek besin değerleriyle
- Porsiyonu baloncuklarla seç → kalori/makro anında hesaplanır
- Hedefe göre (kilo verme/koruma/alma) kişisel günlük bütçe
- Su ve adım takibi, ilerleme grafikleri
- Kurulabilir (PWA) — "ana ekrana ekle"

*Yalnızca Android uygulamasında:* ana ekran widget'ları, bildirimler, yemek fotoğrafları.

## Teknik
Vite + React + TypeScript. Android sürümü Capacitor ile paketlenir. Bu depo web (GitHub Pages)
sürümünün derlenmiş halidir.
